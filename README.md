# Azara · עזרה

Die lebendige Synagoge: 71 Rabbinerfiguren mit den vorhandenen Porträts, jüdischer Jahreskalender, Tagesgebete, Tora und Haftara, Original-Siddurim und Audio.

[Bedienung, Quellen und Funktionsumfang](docs/README.md) · [Rashash-Seitenindex](docs/RASHASH_QUELLEN.md) · [Audioquellen](docs/AUDIO_QUELLEN.md)

```sh
npm ci
npm test
npm run build
npm run dev
```

Die unveränderten hochgeladenen MP3s, Texte und PDF-Scans bleiben Teil des Repositorys. Die App baut sie zusammen mit der Oberfläche nach `dist/`.

## Rashash-Transkriptionen

Die Teile III (HB21519 und HB21520 als getrennte Fassungen), VI (HB21518), VIII (HB21722) und IX (HB21723) sind als Niqqud-Arbeitsfassungen unter **Siddur & Kavvanot → HaRashash · Text mit Niqqud** eingebunden. Jede Fassung besitzt Seitenindex, Suche ohne Niqqud, TXT mit XML-Tags und Scanseitenvergleich. Vorhandene Punktierung und alle Tabellen bleiben unverändert. Bekannte Lücken tragen Prüfvermerke. [Verfahren, Tags und offene Stellen](docs/RASHASH_TRANSKRIPTIONEN.md).
