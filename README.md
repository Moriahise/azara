# Azara · עזרה

Die lebendige Synagoge: 71 Rabbinerfiguren mit den vorhandenen Porträts, jüdischer Jahreskalender, Tagesgebete, Tora und Haftara, Original-Siddurim und Audio.

[Bedienung, Quellen und Funktionsumfang](docs/README.md) · [Rashash-Seitenindex](docs/RASHASH_QUELLEN.md) · [Audioquellen](docs/AUDIO_QUELLEN.md)

```sh
npm ci
npm test
npm run build
npm run dev
```

Die unveränderten hochgeladenen MP3s, Texte und PDF-Scans bleiben Teil des Repositorys. Die App baut sie zusammen mit der Oberfläche nach `dist/`.
